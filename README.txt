RAMALINGAM CARS - CATALOGUE WITH ADMIN ADD / EDIT / DELETE

WHAT IT DOES
- Add up to 40 vehicle listings.
- Upload a photo for each car.
- Edit vehicle details and replace a photo.
- Delete sold vehicles.
- Search/filter the public catalogue.
- Each listing has its own WhatsApp enquiry link.
- Export and import a JSON backup.

HOW TO USE
1. Extract this ZIP.
2. Open index.html in Chrome to preview.
3. Scroll to "Manage Your Car Catalogue".
4. Default admin PIN: 2468
5. IMPORTANT: Change ADMIN_PIN in index.html before publishing.
6. Add, edit or delete cars using the owner dashboard.

IMPORTANT STORAGE LIMITATION
This version stores the inventory and photos in the browser's local storage on the device/browser where changes are made. It is suitable for a single-device demo or local workflow. Visitors to the published website will not automatically see changes made on your phone, and clearing browser data may remove the catalogue. Export backups regularly.
For live public updates from any phone/computer, a shared online database and secure admin login must be connected (for example, Supabase). Do not rely on the browser PIN as production-grade security.
